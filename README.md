# 数研选号后端

FastAPI 服务，负责从中国体彩网和中国福彩网的公开官方页面/接口同步历史开奖，缓存到 SQLite，审计历史样本的随机性，并严格按照官方组合空间等概率生成三组候选。

## 首版覆盖

- 体彩：超级大乐透、排列3、排列5、7星彩
- 福彩：双色球、福彩3D、七乐彩、快乐8（选一至选十）

竞猜型彩票依赖实时比赛、赔率和伤停等外部信息；即开型彩票不存在下一期开奖，因此二者不进入历史号码生成器。

## 本地启动

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload
```

接口文档：<http://localhost:8000/docs>

首次生成某个玩法时，服务会同步该玩法最近最多 `LOTTERY_HISTORY_LIMIT` 期历史数据。默认值为1200，可通过环境变量调整。也可以调用：

```bash
curl -X POST 'http://localhost:8000/api/v1/games/dlt/sync?full=true'
```

抓取完整的官网可用历史。生产环境应保持低频增量更新，并保留 SQLite 数据卷。

## 数学边界

模型将“随机性审计”和“候选生成”严格分开：历史数据只用于多尺度窗口、贝叶斯收缩、严格时序回测、Brier损失、均匀性、熵和自相关诊断；候选生成不使用冷热号权重，而是通过系统加密安全随机源在官方合法组合空间内等概率抽样。

所有合法单注的理论概率相同。公平随机开奖下，不存在仅凭历史数据提升下一期中奖概率的方法。审计中偶然出现的统计偏离也可能来自随机波动、规则变化或数据质量，不能解释为预测优势。
